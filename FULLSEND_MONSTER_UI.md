# FULLSEND MONSTER UI

Esta versão adiciona um sistema visual premium sem alterar a lógica do marketplace.

## Melhorias aplicadas
- Botões principais com brilho direcional.
- Movimento de elevação e clique.
- Glow vermelho controlado.
- Scanline e halo orbital.
- Header com iluminação premium.
- Botões de pesquisa/perfil/admin aprimorados.
- Search shell com acabamento glass.
- Inputs com foco refinado.
- Cards com microinterações.
- Destaque e VIP com aura mais sofisticada.
- Suporte a prefers-reduced-motion.
- Mobile preservado sem animações exageradas.

## Botões principais afetados
- ENTRAR
- CRIAR CONTA
- ANUNCIAR
- NOVO ANÚNCIO
- BUSCAR
- APLICAR FILTROS
- SALVAR PERFIL
- PUBLICAR ANÚNCIO

## Segurança
Nenhuma variável, integração, rota, migration ou banco foi alterado por este pacote de UI.
