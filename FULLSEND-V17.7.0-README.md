# FULLSEND V17.7.0 — COMMUNITY SOCIAL FEED PRO

Base: FULLSEND V17.6.1.

## Alteração principal
Reformulação visual e de UX do mural da Comunidade para priorizar fotos e vídeos e tornar a experiência mais próxima de uma rede social automotiva moderna.

### Feed
- foto/vídeo aparece antes da legenda e com maior destaque;
- galeria com navegação por setas, contador e indicadores;
- duplo clique na mídia para curtir;
- ações Curtir, Comentar, Compartilhar e Salvar redesenhadas;
- quantidade de curtidas em destaque;
- legenda abaixo da mídia;
- textos longos ficam recolhidos e possuem `mais` / `menos`;
- botão para visualizar/ocultar comentários;
- cabeçalho da publicação mais limpo;
- projeto/diário aparecem como contexto compacto acima da mídia;
- layout responsivo para desktop e celular.

## Segurança e compatibilidade
Nenhuma tabela ou API nova foi criada. As rotas e ações existentes da Comunidade foram preservadas.

## SQL
Não há nova migration para a V17.7.0.
